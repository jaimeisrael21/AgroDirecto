# AgroDirecto — Avance 1

Prototipo académico del curso Desarrollo Full Stack (UTP, sección 45554). Conecta productores agrícolas con compradores locales y permite explorar productos, registrar solicitudes sin cobro y gestionar pedidos por rol.

## Alcance actual

- 12 pantallas funcionales.
- Roles de comprador, productor y administrador.
- Catálogo, detalle, mapa aproximado, carrito y seguimiento.
- Regla de un solo productor por pedido.
- Persistencia de demostración con `localStorage`.
- Sin pagos reales, IA, hardware ni almacenamiento de contraseñas.

## Tecnologías

- React 19 y TypeScript.
- Vinext/Vite.
- Bootstrap 5 y CSS personalizado.
- Leaflet con OpenStreetMap.

## Ejecutar localmente

```bash
pnpm install
pnpm run dev
```

Abrir `http://localhost:3000/`.

## Verificación

```bash
pnpm run build
```
